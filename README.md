# BlindPass Homebrew tap

```bash
brew install blindpass-app/tap/blindpass
```

`blindpass` runs commands with secrets from your BlindPass vault without printing them. See <https://blindpass.app>.

`Formula/blindpass.rb` is published automatically with each BlindPass release; changes made here are overwritten.

Other systems: `curl -fsSL https://blindpass.app/cli/install.sh | sh` (macOS, Linux) or `irm https://blindpass.app/cli/install.ps1 | iex` (Windows).
